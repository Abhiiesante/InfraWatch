## Dashboard Aggregations

Dashboard endpoints return synchronously calculated, high-level metrics meant to be displayed on the frontend overview screens. Because these can be expensive to calculate, the `DashboardController` relies on aggressive Redis caching (TTL: 5 minutes) in V0.

### GET /api/v1/dashboard/metrics
Retrieves global KPIs for the tenant.

**Security:** `JWT` (Any Role)

#### Responses
**200 OK**
```json
{
  "totalAssets": 124,
  "activeCameras": 45,
  "offlineCameras": 3,
  "openIncidents": {
    "CRITICAL": 1,
    "HIGH": 4,
    "MEDIUM": 12,
    "LOW": 5
  },
  "inspectionsThisWeek": 24,
  "complianceRate": 92.5
}
```

## Asynchronous Reports

Generating PDF reports or massive CSV exports is handled asynchronously.

### POST /api/v1/reports
Initiates the generation of a new report and delegates it to a background worker.

**Security:** `JWT` (ADMIN, MANAGER)

#### Request Body
```json
{
  "title": "Q3 Incident Summary",
  "reportType": "INCIDENT_SUMMARY",
  "startDate": "2026-07-01T00:00:00Z",
  "endDate": "2026-09-30T23:59:59Z"
}
```

#### Responses
**202 Accepted** (Indicates the request is valid and processing has begun)
```json
{
  "message": "Report generation started",
  "reportId": 402,
  "status": "PENDING"
}
```

---

### GET /api/v1/reports
Retrieves a list of all historical and pending reports generated by the tenant.

**Security:** `JWT` (ADMIN, MANAGER)

#### Query Parameters
- `page`, `limit`

#### Responses
**200 OK**
```json
{
  "items": [
    {
      "id": 402,
      "title": "Q3 Incident Summary",
      "reportType": "INCIDENT_SUMMARY",
      "status": "PENDING",
      "createdAt": "2026-07-16T10:00:00Z",
      "url": null
    },
    {
      "id": 401,
      "title": "Q2 Compliance Audit",
      "reportType": "COMPLIANCE",
      "status": "COMPLETED",
      "createdAt": "2026-04-01T10:00:00Z",
      "url": "https://s3.amazonaws.com/infrawatch-bucket/reports/..."
    }
  ],
  "total": 2,
  "page": 1,
  "limit": 20,
  "totalPages": 1
}
```

---

### GET /api/v1/reports/:id
Poll this endpoint to check the status of a specific report. 

**Security:** `JWT` (ADMIN, MANAGER)

#### Responses
**200 OK** (While generating)
```json
{
  "id": 402,
  "status": "PENDING",
  "url": null
}
```

**200 OK** (When complete)
```json
{
  "id": 402,
  "status": "COMPLETED",
  "url": "https://s3.amazonaws.com/infrawatch-bucket/reports/1/402/Q3_Incident_Summary.pdf"
}
```

**500 Internal Server Error** (If worker failed)
```json
{
  "id": 402,
  "status": "FAILED",
  "url": null,
  "errorMessage": "Failed to parse data for PDF generation"
}
```
