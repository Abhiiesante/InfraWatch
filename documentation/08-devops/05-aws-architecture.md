## Network Topology (VPC)

The production environment operates within a Virtual Private Cloud (VPC) spanning two Availability Zones (AZs) to ensure High Availability (HA).

- **Public Subnets:** Contains the Application Load Balancer (ALB) and NAT Gateways. Resources here are reachable from the internet.
- **Private Subnets (App):** Contains the ECS Fargate tasks (API and Worker). They have no public IP addresses. They access the internet (for sending emails, pulling images) via the NAT Gateway in the Public Subnet.
- **Private Subnets (Data):** Contains the RDS PostgreSQL database and ElastiCache Redis cluster. These subnets have no route to the internet whatsoever.

---

## Compute (ECS Fargate)

We use AWS Elastic Container Service (ECS) with the Fargate launch type. Fargate is "serverless compute for containers"—we don't manage the underlying EC2 instances or OS updates.

- **API Service:** Runs as a Fargate Service behind the ALB. Configured with Auto Scaling based on CPU utilization (target 70%).
- **Worker Service:** Runs as a Fargate Service with no ALB attached. Pulls jobs from Redis. Scaled independently based on queue length.

## Data Persistence (RDS & ElastiCache)

### Amazon RDS (PostgreSQL)
We use a Multi-AZ RDS instance. If the primary database instance fails, AWS automatically fails over to a synchronous standby replica in the second AZ, updating the DNS endpoint invisibly.
- Backups are automated with a 7-day retention period.
- Storage is encrypted at rest using AWS KMS.

### Amazon ElastiCache (Redis)
Used for BullMQ and API rate limiting. We use a 2-node cluster (Primary and Replica) in the private data subnets.

## Storage & Content Delivery (S3 & CloudFront)

### Amazon S3
We use two distinct S3 buckets:
1. `infrawatch-assets-[env]`: Stores user-uploaded inspection images and generated PDF reports. Not publicly readable (files are accessed via pre-signed URLs generated by the API).
2. `infrawatch-frontend-[env]`: Stores the compiled static assets of the React SPA.

### Amazon CloudFront
A CDN placed in front of the `infrawatch-frontend` S3 bucket. It caches the React application at edge locations worldwide, providing SSL termination (using AWS Certificate Manager) and routing 404s back to `index.html`.
